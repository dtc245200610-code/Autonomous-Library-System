Bảng Đối Chiếu 7 Tiêu Chí Đánh Giá (Điểm 10/10)

1. Quản lý mã nguồn trên GitHub (1.5 điểm)

• Đầy đủ mã nguồn, cấu hình Docker, Nginx, Prometheus, Grafana, Loki.

• Có sẵn script setup_git.bat tạo tự động 3 commit chuẩn ý nghĩa (Core, DevOps, Monitoring).

• README.md chi tiết hướng dẫn chạy 1 lệnh và giải thích kiến trúc.

2. Triển khai ứng dụng + Database (1.5 điểm)

• PostgreSQL 16 chạy ổn định, có sẵn init.sql nạp sẵn 8 sách, 5 độc giả, 5 phiếu mượn.

• pgAdmin 4 được cấu hình sẵn tự động nhận diện DB server qua file servers.json, không cần nhập thủ công.

3. Nginx Reverse Proxy (1.5 điểm)

• Cổng 80 duy nhất làm Gateway điều hướng toàn bộ hệ thống (Web: /, pgAdmin: /pgadmin/, Grafana: /grafana/).

• Tích hợp đầy đủ OWASP Security Headers (X-Frame-Options, CSP, HSTS ready, nosniff, Rate Limiting).

4. Hệ thống giám sát (Prometheus + Grafana) (1.5 điểm)

• Prometheus tự động scrape endpoint /metrics từ Web App (HTTP requests, latency, active loans, total books).

• Grafana tự động nạp sẵn Dashboard JSON trực quan hóa hiệu năng container và hoạt động thư viện.

5. Hệ thống log tập trung (Loki + Promtail) (1.5 điểm)

• Promtail thu thập log container thời gian thực và đẩy vào Loki.

• 3 Query LogQL cơ bản chuẩn bị sẵn:

1. {job="library_app"} |= "BORROW_SUCCESS" 2. {job="library_app"} | json | level="ERROR" 3. rate({job="library_nginx"}[1m])

6. Hardening hệ thống (1.5 điểm)

• Non-root container: Web App chạy dưới UID 10001 (appuser).

• Network Isolation: Tách biệt 3 subnet (frontend_net, backend_net, monitor_net). PostgreSQL KHÔNG publish port ra ngoài host.

• Database Least Privilege: Ứng dụng chỉ dùng tài khoản lib_app (SELECT/INSERT/UPDATE, cấm DROP/ALTER).

• Mật khẩu mạnh & Secret: Quản lý toàn bộ qua biến môi trường .env bí mật.

7. Tổng thể & Trình bày (1.0 điểm)

• Khởi chạy toàn bộ hệ thống bằng 1 lệnh duy nhất: docker compose up -d hoặc file start.bat.
